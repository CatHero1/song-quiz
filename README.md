# song-quiz
App developed with claude for the song quiz game

Hear a short clip, guess the song and the artist. 5 rounds, any number of players taking turns, 10 points each for title and artist, double points in the last round. Classic mode: answer out loud like Alexa, or type it, with up to 2 replays per turn. Heardle mode: start with 1 second of the song and unlock more with each skip or wrong guess.

Play it at https://cathero1.github.io/song-quiz/

Songs and clips come from Deezer's public API. The whole app is `index.html`.
