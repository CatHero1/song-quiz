# song-quiz
App developed with claude for the song quiz game

Hear a short clip, guess the song and the artist. 5 rounds, any number of players taking turns, 10 points each for title and artist, double points in the last round. Answer out loud like Alexa, or type it. Up to 2 replays per turn, or skip.

Play it at https://cathero1.github.io/song-quiz/

Songs and clips come from Deezer's public API. The whole app is `index.html`.
